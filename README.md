# 🏦 Banking Management System (C++)

A console-based **Banking Management System** developed using **C++ and Object-Oriented Programming (OOP)**. This project provides basic banking operations such as creating accounts, depositing money, withdrawing money, searching for accounts, modifying account details, and deleting accounts.

## 📌 Project Overview

The Banking Management System is designed to simplify basic banking operations through a menu-driven interface. It uses C++ classes and file handling to manage customer account information and maintain records even after the program is closed.

## ✨ Features

- **Create Account:** Register a new bank account.
- **Deposit Money:** Add money to an existing account.
- **Withdraw Money:** Withdraw money while checking account balance.
- **Search Account:** Find and view account details.
- **Modify Account:** Update existing account information.
- **Delete Account:** Remove an account record.
- **File Handling:** Store account information for future use.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming (OOP)
- **Storage:** File Handling
- **Interface:** Console-based menu system

## 🧠 OOP Concepts Implemented

The project demonstrates the following OOP concepts:

- **Classes and Objects:** Used to represent and manage bank accounts.
- **Inheritance:** `CurrentAccount` and `SavingsAccount` inherit properties and functionality from the `Account` class.
- **Encapsulation:** Account data and related operations are organized within classes.
- **Abstraction:** Banking operations are provided through simple methods, hiding implementation details.

## 🏗️ Project Structure

The project is organized around the following main classes:

| Class | Purpose |
|---|---|
| `Account` | Stores and manages common account information. |
| `CurrentAccount` | Represents a current bank account. |
| `SavingsAccount` | Represents a savings bank account. |
| `FileManager` | Handles storing and retrieving account records. |
